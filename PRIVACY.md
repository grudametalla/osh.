# Конфиденциальность osh. (публичная бета)

Редакция: 28 сентября 2026 года.

osh. обрабатывает сетевой трафик, необходимый для работы
выбранных вами функций подключения. Telegram Bridge использует
локальный прокси; Smart Access применяет Android VPN-интерфейс
для маршрутизации трафика выбранных сервисов.

**По текущей реализации** приложение не содержит встроенной
рекламной аналитики и не отправляет владельцу osh. содержимое
сообщений, медиафайлов или историю посещения сайтов.
Настройки и технические статусы сохраняются на устройстве.

Приложение может обращаться к GitHub для поиска обновлений,
к серверным адресам соответствующих сервисов и к диагностическим
сетевым узлам для проверки доступности. Внешние сервисы получают
обычные сетевые запросы согласно своим политикам конфиденциальности.

Запуск локальных диагностик и экспорт отчётов осуществляются
в приложении. Перед передачей отчёта третьим лицам проверяйте,
что он не содержит нежелательных для разглашения сведений.

Приложение запрашивает доступ к интернету, состоянию сети,
VPN-сервису, уведомлениям и автозапуску для предусмотренных функций.
Разрешение на установку APK используется **только** для запуска
системного установщика при явно подтверждённом обновлении.

Данный текст описывает текущую публичную бета-версию.
Если позднее появятся учётные записи, платные сервисы или
серверная лицензия, политика будет дополнена **до их включения**.

Приложение не предназначено для сокрытия личности в интернете.
