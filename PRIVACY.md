# Конфиденциальность osh. (публичная бета)

Редакция: 30 сентября 2026 года.

osh. обрабатывает сетевой трафик, необходимый для работы
выбранных вами функций подключения. Telegram Bridge использует
локальный прокси; Smart Access применяет Android VPN-интерфейс
для маршрутизации трафика выбранных сервисов.

**По текущей реализации** приложение не содержит встроенной
рекламной аналитики и не отправляет владельцу osh. содержимое
сообщений, медиафайлов или историю посещения сайтов.
Настройки и технические статусы сохраняются на устройстве.

Приложение может обращаться к GitHub для поиска обновлений,
к серверным адресам соответствующих сервисов и к диагностическим
сетевым узлам для проверки доступности. Внешние сервисы получают
обычные сетевые запросы согласно своим политикам конфиденциальности.

Telegram Bridge при некоторых маршрутах может использовать сторонние
публичные relay/proxy-домены как транспортный промежуточный узел.
Такой узел не получает от osh. содержимое Telegram-сообщений в открытом
виде, но как участник сетевого маршрута может видеть факт соединения,
его время, объём трафика и другие обычные транспортные метаданные.
Конкретные relay-hostnames могут меняться между версиями приложения.

Запуск локальных диагностик и экспорт отчётов осуществляются
в приложении. osh. не загружает диагностические отчёты автоматически:
передача начинается только через системное меню отправки Android.
Перед передачей отчёта третьим лицам проверяйте, что он не содержит
нежелательных для разглашения сведений.

## Хранение на устройстве

Настройки приложения и локальные технические состояния хранятся в
закрытом хранилище приложения. Локальные Telegram/proxy-секреты
защищаются ключом Android Keystore и сохраняются до сброса
соответствующих данных, очистки данных приложения или удаления osh.
Обычный Android backup и device transfer для приватных данных отключены.

Диагностика хранит не более **5 диагностических отчётов**, а длительный
soak-тест — не более **3 отчётов длительного теста**; более старые файлы
удаляются автоматически. Рабочие журналы ограничены по размеру и числу
записей. Экспорт даёт выбранному приложению временное право чтения
конкретного файла через FileProvider.

Загруженный APK обновления хранится в кэше обновлений приложения на
время установки. Отвергнутые, повреждённые и устаревшие копии удаляются;
оставшийся кэш может быть очищен Android или пользователем.

Приложение запрашивает доступ к интернету, состоянию сети,
VPN-сервису, уведомлениям и автозапуску для предусмотренных функций.
Разрешение на установку APK используется **только** для запуска
системного установщика при явно подтверждённом обновлении.

Данный текст описывает текущую публичную бета-версию.
Если позднее появятся учётные записи, платные сервисы или
серверная лицензия, политика будет дополнена **до их включения**.

Приложение не предназначено для сокрытия личности в интернете.
