# osh. для Android

**osh.** помогает поддерживать соединение с Telegram, YouTube и Discord
в сетях с ограничениями. Для Telegram используется локальный мост;
для YouTube и Discord предусмотрен общий Android VPN-маршрут Smart Access.

> Публичная бета. Совместимость зависит от версии Android, оператора,
> текущей сети и ограничений доступа. Успешное подключение к локальному
> прокси не гарантирует доступность сервиса в конкретной сети.

## Установка

1. Откройте вкладку **Releases** этого репозитория.
2. Для обычного Android-телефона (ARM64) выберите файл
   `osh-<версия>-arm64-v8a.apk`. Универсальный APK также
   поддерживает эмуляторы x86_64.
3. Проверьте подпись и контрольную сумму согласно [INSTALL.md](INSTALL.md).
4. Подтвердите установку в Android, пройдите первичную настройку.
5. Обновления ищутся в этом же публичном репозитории; Android
   **всегда** просит подтверждение установки нового APK.

Обычные ошибки, вопросы по установке и обращения в поддержку
можно сообщать через **Issues** этого репозитория. Укажите версию osh.,
версию Android и краткое описание проблемы. Не публикуйте там токены,
пароли, содержимое переписок, диагностические дампы или детали
уязвимостей. Для проблем безопасности используйте порядок из
[SECURITY.md](SECURITY.md).

Официальный релиз должен находиться только в **Releases** этого
репозитория и содержать подписанные APK, `SHA256SUMS.txt` и
`RELEASE-METADATA.json`. Контрольные суммы подтверждают целостность,
а подлинность APK проверяется по production-сертификату из
[INSTALL.md](INSTALL.md).

Если вы нашли поддельный сайт, репак или APK, который выдаёт себя за
osh., создайте обычный Issue без секретов: приложите ссылку, имя файла,
SHA-256 и отпечаток сертификата, если они известны. Порядок проверки и
запроса на удаление описан в [SECURITY.md](SECURITY.md).

Здесь распространяются **только подписанные сборки APK и метаданные
релизов**. Исходный код osh. является закрытым и в этот
репозиторий не загружается.

osh. не является VPN-сервисом анонимизации и не гарантирует
доступность сторонних сайтов во всех сетях.
