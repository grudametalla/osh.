# Безопасность и сообщения об уязвимостях

Пользуйтесь только APK, опубликованными в разделе **Releases**
этого репозитория. Контрольные суммы `SHA256SUMS.txt` и
`RELEASE-METADATA.json` позволяют сверить скачанный файл.

Выпуски подписаны постоянным production-сертификатом osh.
SHA-256 отпечаток официального сертификата:
`a5327cd2a2c0c48e6805467ae22cc5db83a7fd54c84715d1cc9dc94c5f6c0c9c`.

Он опубликован до первого APK-релиза. При обновлении Android
проверяет подпись пакета; osh. также сверяет сертификат
загруженного APK с установленным приложением.

Обновления **не** устанавливаются скрытно. Системный установщик
Android требует участия пользователя.

Для сообщения об уязвимости используйте включённую для этого
репозитория функцию **Private vulnerability reporting / Security advisory**
GitHub. Не публикуйте детали эксплуатации, пользовательские данные,
секреты или файлы дампа в обычных Issues. Если приватная форма GitHub
недоступна из вашего аккаунта, откройте Issue только с запросом
защищённого канала связи, без технических деталей уязвимости.

Уточняйте версию APK, версию Android, ожидаемое и фактическое
поведение. Не проверяйте уязвимости на устройствах других людей.

Исходники osh. не публикуются в данном бинарном репозитории.
