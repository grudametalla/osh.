# Безопасность и сообщения об уязвимостях

Пользуйтесь только APK, опубликованными в разделе **Releases**
этого репозитория. Контрольные суммы `SHA256SUMS.txt` и
`RELEASE-METADATA.json` позволяют сверить скачанный файл.

Выпуски подписаны сертификатом osh. При обновлении
Android проверяет подпись пакета; osh. также сверяет
сертификат загруженного APK с установленным приложением.

Обновления **не** устанавливаются скрытно. Системный установщик
Android требует участия пользователя.

Для сообщения об уязвимости воспользуйтесь приватным
**Security advisory** GitHub, если он включён в репозитории.
Если он недоступен, откройте Issue с запросом защищённого
канала связи **без публикации деталей эксплуатации,
пользовательских данных, секретов или файлов дампа**.

Уточняйте версию APK, версию Android, ожидаемое и фактическое
поведение. Не проверяйте уязвимости на устройствах других людей.

Исходники osh. не публикуются в данном бинарном репозитории.
