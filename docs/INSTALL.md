# Установка и проверка APK

**Русский** · [English](INSTALL_EN.md)

## Как выбрать файл

- `osh-<version>-arm64-v8a.apk`: основной вариант для Android ARM64.
- `osh-<version>-universal.apk`: ARM64 и x86_64 в одном APK.
- `SHA256SUMS.txt`: контрольные суммы файлов конкретного релиза.
- `RELEASE-METADATA.json`: номер версии, исходный коммит, отпечаток
  сертификата подписи и контрольные суммы APK.

Загружайте APK **только из Releases этого репозитория**.
Не устанавливайте перепакованные или переподписанные сборки,
предлагаемые на посторонних сайтах.

## Проверка целостности

На Windows PowerShell:
```powershell
Get-FileHash .\osh-0.1.0-beta.1-arm64-v8a.apk -Algorithm SHA256
```

Сравните результат со строкой для того же имени файла в `SHA256SUMS.txt`.
Это проверяет целостность скачанного APK относительно файла контрольных
сумм, **но не подтверждает подлинность**, если злоумышленник подменил
и APK, и контрольные суммы.

Отпечаток сертификата можно проверить командой
`apksigner verify --print-certs имя-файла.apk` из Android SDK.
Сверьте его с **официальным отпечатком, полученным заранее по независимому
проверенному каналу**, а не только с `releaseCertificateSha256` из
того же релиза: метаданные тоже могут быть подменены вместе с APK.
Официальный SHA-256 отпечаток production-сертификата osh.:
`a5327cd2a2c0c48e6805467ae22cc5db83a7fd54c84715d1cc9dc94c5f6c0c9c`.

Этот отпечаток опубликован в репозитории **до первого APK-релиза**.
Если установленный или скачанный APK подписан другим сертификатом,
не устанавливайте его как официальный osh.

## Обновление

При появлении обновления приложение предложит скачать подписанный APK
и передать его системному установщику Android. Автоматической тихой
установки нет. Android может попросить разрешить установку из osh.

Для обновления **без удаления приложения** требуется официальная сборка с тем же сертификатом подписи и более высоким `versionCode`. Не удаляйте приложение без необходимости: локальные настройки могут быть потеряны.

## Если не работает

Если Android блокирует установку, проверьте разрешение на установку
для приложения-источника. Если Telegram, YouTube или Discord не
подключаются, запишите версию, Android, сеть и диагностический статус,
не прикладывая сообщения, токены, адреса переписок или пароли.
