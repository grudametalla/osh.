# Возможности osh.

**Русский** · [English](FEATURES_EN.md)

## Telegram Bridge

osh. поднимает локальный прокси на устройстве и передаёт готовые параметры в Telegram. Пользователю не нужно вручную копировать адреса и порты.

Мост работает отдельно от Android VPN, поэтому Telegram можно использовать независимо от Smart Access.

## Smart Access

Smart Access предназначен для YouTube и Discord.

- один Android VPN используется сразу для обоих приложений;
- в туннель попадает трафик только выбранных приложений;
- остальные приложения продолжают работать через обычное соединение;
- маршруты выбираются автоматически;
- при сбое osh. пытается восстановить проблемный маршрут без перезапуска всего приложения.

## Режимы подключения

**Авто** подходит для обычного использования: osh. сам подбирает маршрут и восстанавливает соединение.

**Вручную** оставляет больше контроля и полезен для диагностики нестандартных сетей.

## Смена сети и восстановление

Приложение отслеживает смену Wi-Fi/LTE и состояние активного маршрута. При временном обрыве osh. повторяет подключение и старается не затрагивать сервисы, которые продолжают работать.

## Проверка соединения

Раздел «Проверка» запускает диагностику и помогает понять, на каком этапе возникла проблема. Диагностические данные можно экспортировать вручную.

## Системные функции

- автозапуск после перезагрузки;
- плитка быстрых настроек Android;
- уведомление активного фонового сервиса;
- обновление через системный установщик Android;
- проверка подписи загруженного APK перед обновлением.

## Приватность

osh. не содержит встроенной рекламной аналитики и не отправляет владельцу приложения содержимое сообщений или историю посещения сайтов.

Настройки и технические состояния хранятся локально. Подробности: [PRIVACY.md](PRIVACY.md).

## Ограничения публичной беты

- доступность Telegram, YouTube и Discord зависит от конкретной сети;
- Android разрешает только один активный VPNService, поэтому Smart Access может конфликтовать с другим VPN;
- приложение не предназначено для анонимизации всего трафика;
- отдельные маршруты и методы подключения могут меняться между версиями.

Текущий релиз и изменения публикуются в [Releases](https://github.com/grudametalla/osh./releases).
